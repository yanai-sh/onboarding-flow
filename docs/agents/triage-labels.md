# Triage Labels

This repository uses local Markdown planning for a small, solo interview
assignment. These labels describe the state of work without introducing a
remote project-management system.

| Skill role | Project label | Meaning |
| --- | --- | --- |
| `needs-triage` | `inbox` | A new idea, task, or finding has not been evaluated yet. |
| `needs-info` | `needs-clarification` | Progress depends on an unresolved assignment detail, platform behavior, or decision. |
| `ready-for-agent` | `ready-to-build` | The work is sufficiently specified for implementation. |
| `ready-for-human` | `manual-platform-step` | The work requires a human action in Insait, account approval, recording, or another external UI. |
| `wontfix` | `out-of-scope` | Deliberately excluded to protect a focused, credible take-home submission. |

Use the project label in issue `Status:` lines and local planning notes. Keep
the skill role on the left unchanged so the installed skills continue to
interpret the workflow correctly.
